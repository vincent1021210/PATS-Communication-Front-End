PATS Coturn（跨網段／4G 通話中繼）
==================================

同 Wi‑Fi 通常只靠 STUN 就能打通。
不同網路（家裡打給 4G、公司防火牆）才需要 TURN。

推薦：獨立 Docker 包（信令可繼續用 Render）
  → 詳見 voip/coturn/部署說明.txt

若要 Oracle 同機裝「HTTPS 信令 + Coturn」
  → 詳見 voip/oracle-free/部署說明.txt


快速步驟（Docker）
------------------
1. 租一台有公網 IP 的 VPS（Oracle Always Free 即可；Render Free 不適合）
2. 上傳 voip/coturn/ 到主機
3. cp .env.example .env → 填 PUBLIC_IP、TURN_PASS
4. ./gen-conf.sh && docker compose up -d
5. 防火牆放行：TCP/UDP 3478、UDP 49152-65535
6. 前端 assets/js/config.js 的 iceServers 加上：
     { urls: 'turn:你的公網IP:3478', username: 'pats', credential: '你的密碼' }
7. 推 GitHub Pages、雙方強制重新整理


無 Docker（apt）
----------------
  sudo apt update && sudo apt install coturn
  把 voip/turnserver.conf 或 voip/coturn/turnserver.conf 拷到 /etc/turnserver.conf
  改 external-ip、user=
  sudo sed -i 's/#TURNSERVER_ENABLED=1/TURNSERVER_ENABLED=1/' /etc/default/coturn
  sudo systemctl restart coturn


注意
----
- TURN 帳密會出現在前端，請視為「可被看到的中繼密碼」
- 填好 Coturn 後 call.js 會優先用它（不再走公共 Open Relay）
