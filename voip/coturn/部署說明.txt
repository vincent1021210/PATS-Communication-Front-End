PATS × Coturn（自架 TURN）
========================
信令可繼續用 Render；Coturn 只負責跨網／4G 的媒體中繼。
需要一台「有公網 IP」的 Linux（Oracle Always Free 即可）。
Render Free 不適合跑 Coturn（UDP 中繼埠受限）。


一、防火牆（主機 + 雲端 Security List）
----------------------------------------
  TCP/UDP  3478
  UDP      49152-65535


二、在 VPS 上啟動
----------------------------------------
  # 上傳本資料夾後：
  cd voip/coturn
  cp .env.example .env
  nano .env          # 填 PUBLIC_IP、TURN_PASS
  chmod +x gen-conf.sh
  ./gen-conf.sh
  docker compose up -d

  # 沒有 Docker 時改用系統套件：
  #   sudo apt install coturn
  #   把 turnserver.conf 拷到 /etc/turnserver.conf
  #   啟用 /etc/default/coturn 的 TURNSERVER_ENABLED=1
  #   sudo systemctl restart coturn


三、前端接上 Coturn
----------------------------------------
編輯 assets/js/config.js 的 iceServers，取消註解並改成你的 IP／密碼：

  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
    { urls: 'turn:你的公網IP:3478', username: 'pats', credential: '你的密碼' }
  ]

有填 turn: 時，call.js 會優先用 Coturn（iceSource: coturn），
不再走公共 Open Relay。

推上 GitHub Pages 後雙方強制重新整理。


四、驗證
----------------------------------------
1. VPS：docker compose ps（coturn 應為 Up）
2. 桌面 Console：[PATS-dbg] ice servers resolved → iceSource:"coturn"、hasTurn:true
3. 撥號後應出現 local ice candidate type:"relay"
4. 跨 4G／不同 Wi‑Fi 應能接通


五、進階（信令 + Coturn 同機）
----------------------------------------
